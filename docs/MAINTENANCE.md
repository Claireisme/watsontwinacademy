# 学院后台日常维护

进入正式网址 `/admin`，使用获准的管理员邮箱登录。

## 更新课程／课表／费用

1. 打开 **Classes & timetable**，点击课程右侧 Edit。
2. 编辑名称、描述、年龄／基础、费用和时间。多行课表会保留换行。
3. 上传照片或使用现有图片路径。
4. 勾选 Published 才会在官网展示；取消勾选相当于下架，历史咨询保留。
5. Save 后打开前台查看。无需重新部署。

Page address 是课程网址的一部分。修改后系统会自动为旧地址保留301跳转；旧地址不能再分配给其他课程。Display order 数字越小越靠前。

出现“另一位管理员已更新”的提示，请刷新后重新合并自己的修改，系统不会静默覆盖对方内容。

## 更新首页、故事和联系信息

进入 **Home & settings**。首页标题支持换行。联系方式会同步用于联系页及相关全站位置。公共联系邮箱与收咨询通知的 Gmail 独立：后者只能在 Cloudflare 的 `NOTIFICATION_EMAIL` 修改。

隐私说明也在这里维护。正式上线前确认实际数据用途和保留期，不要把示例政策当作已完成审查。

## 维护相册

进入 **Photo gallery**，Add a photo → 上传 → 填写准确的图片说明 → 保存。

支持 JPEG、PNG、WebP，单张最大5 MB，不接受 SVG。上传后仍需点击保存才会出现在页面。只发布已获授权的图片；留意照片元数据和未成年人肖像权限。

从相册移除仅删除展示记录，R2 文件仍保留，因为同一图片可能被课程使用。清理不再使用的 R2 文件前，先核查所有课程和相册引用；公开缓存中的副本可能不会立即消失。

## 跟进咨询

进入 **Enquiries**：

- New：待处理。
- Contacted：已联系。
- Enrolled：已确认入学。
- Closed：已结束。

状态只是工作人员记录，不会自动给家长发送报名确认。通过 Gmail 回复家长，或点击咨询中的邮箱／电话。

Email 状态不是 `sent` 时检查原因；修复邮件配置后点击 Retry notification。`sent` 表示供应商接受邮件，不保证收件箱投递。持续失败时不要反复点击，应检查 Cloudflare 环境变量及供应商控制台。

删除记录会删除网站数据库中的咨询和邮件任务，但已经发送到 Gmail 的邮件不会被删除；如处理删除请求，需同时处理邮箱及其他实际副本。

## 建议的维护节奏

- 每个工作日：新咨询和邮件失败记录。
- 每学期开课前：课程、年龄、课表、费用及入学说明。
- 每月：电话邮箱、图片、内容链接及页面实际显示。
- 按学院确定的保留规则：清理过期咨询，并处理 Gmail 副本。
- 技术维护：依赖更新、备份／恢复验证、权限检查及部署监控。

**Activity log** 记录最近100条管理员操作，包括操作者、动作、记录ID和时间，不复制家长留言正文。
